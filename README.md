# Gen-data-TL

Repository dành cho việc tạo và quản lý dữ liệu training/learning.

Repository for generating and managing training/learning data.

## 📤 Cách Upload Folder / How to Upload Folders

**Xem hướng dẫn chi tiết tại:** [UPLOAD_GUIDE.md](./UPLOAD_GUIDE.md)

**See detailed instructions at:** [UPLOAD_GUIDE.md](./UPLOAD_GUIDE.md)

### Nhanh chóng / Quick Start:

#### Sử dụng Git Command Line:
```bash
# Clone repository
git clone https://github.com/dongmino042/Gen-data-TL.git
cd Gen-data-TL

# Copy folder của bạn vào đây / Copy your folder here

# Upload lên GitHub / Upload to GitHub
git add .
git commit -m "Thêm dữ liệu mới / Add new data"
git push origin main
```

#### Sử dụng GitHub Web:
1. Truy cập: https://github.com/dongmino042/Gen-data-TL
2. Click **Add file** → **Upload files**
3. Kéo thả folder hoặc chọn files
4. Click **Commit changes**
